# 个人档案网站 · v2

## 本地打开

直接双击 `index.html`，在 Safari、Chrome 或 Edge 里就能打开。**不用搭服务器，不用安装依赖，不用联网。**

## 这版有什么变化

- 侧边 5 张可切换的档案索引（首页、作品、文字、关于、联系）；桌面端索引始终悬浮可见，手机上改成顶部固定横排标签。
- 每次只打开一页内容，并有轻微的「抽出档案页」动画；浏览器地址里的 `#works`、`#writing` 等可直接链接到具体页面。
- 删除独立的「工作方法」页面：一本书是一项完整项目，具体判断、编辑工作和作品结果都记录在每一本书的详情里。
- 根据之前上传的 13 张实际书封制作了 12 张不同作品卡片。两版《制造消费者》中沿用黑黄版；另一张橙白版 `s35107328.jpg` 保留在 assets/covers，未被删除。
- 每本书卡片单独设置「成绩」栏（留空待核实），豆瓣图书直达链接和详细项目档案。

## 怎么填写真实内容

用文本编辑器打开 `content.js`。

- **个人信息：** `site.displayName` 是显示名称，`site.intro` 是首页介绍；`email` 与 `socialUrl` 分别是联系方式。
- **每本书：** 在 `projects` 里按 id 编辑 `role`（实际职责）、`insight`（关键判断）、`work`（本人做的工作）、`result`（成绩），这些都可以是完整的一段话，不用被固定流程强行拆分。
- **出版年份：** `year`。作品以题材分类，`category` 应从 `categories` 列表中选。新增书时复制一个项目对象，改 id、封面和文字。
- **豆瓣链接：** `douban` 需要填该书图书详情页 `https://book.douban.com/subject/数字/`，不是书评页或搜索结果。当前《跳动的心》链接未能确认，暂使用标注清楚的搜索页 `doubanSearch`，切勿误以为是详情页。
- **书封：** 把文件放 `assets/covers/`，再在项目的 `cover` 填 `assets/covers/文件名.jpg`。所有图片都保存在网站内，不依赖豆瓣图片服务器，因此本地离线正常显示。
- **文章：** `articles` 里的 `paragraphs` 是正文段落数组。目前的三篇都是明确标注的演示文章，公开上线前请改成自己的文字或删掉。

## 公开发布

本网站使用 HTML、CSS、JavaScript 和本地图片，没用 React 和打包工具。
将本文件夹的所有内容上传到静态网站服务（例如 GitHub Pages、Cloudflare Pages 等）即可。无需更改代码结构。国内访问速度和备案要求因托管方案、域名和接入区域而异，需要正式发布时再确定。

## 注意

书籍出版信息和封面不等于已经核实本人每个项目的确切职责。所有职责与个人成绩留空，不会自动杜撰。豆瓣外链需联网才可以访问。
